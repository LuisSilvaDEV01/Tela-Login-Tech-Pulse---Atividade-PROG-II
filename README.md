# Tech Pulse - Tela de Login

Projeto acadêmico desenvolvido com foco em uma tela de login inspirada na identidade visual da **Tech Pulse**, utilizando apenas **HTML**, **CSS** e **JavaScript**.

## Sobre o projeto

A proposta deste trabalho foi criar uma interface moderna e responsiva para login, seguindo a linha visual da empresa Tech Pulse e aplicando conceitos básicos de estruturação, estilização e interatividade no front-end.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Layout responsivo
- Menu dropdown
- Alternância entre `dark mode` e `light mode`
- Troca automática da logo conforme o tema
- Formulário de login com `event.preventDefault()`
- Links visuais de `Cadastre-se` e `Esqueceu sua senha?`
- Alertas demonstrativos para ações do formulário

## Estrutura do projeto

```bash
.
|-- index.html
|-- style.css
|-- script.js
`-- assets/
    `-- techpulse/
        |-- logo04.png
        `-- logo2.png
```

## Como visualizar

Basta abrir o arquivo `index.html` no navegador.

## Observações

- O projeto tem fins acadêmicos.
- Não há integração com backend.
- As ações do formulário são demonstrativas.
